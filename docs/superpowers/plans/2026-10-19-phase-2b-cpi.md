# Phase 2B CPI and Inflation Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ingest, validate, store, analyse and display Stats NZ CPI so the 22 Oct 2026 "September 2026 quarter" release flows through the existing pipeline with no code change.

**Architecture:** A `CpiAdapter` (slug `consumers-price-index`) parses three official CSVs plus the release page's embedded charts into the existing `ParsedBundle`, validates fail-closed, and persists through the unchanged ingest transaction. Percent changes are derived on read by a pure `stats/cpi.py`. A `GET /api/cpi` bundle, a rule-based release analysis and a `/inflation` React page mirror the ECT implementation.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, SQLite, pytest, ruff; React 19, TypeScript, Vite, Tailwind 4, ECharts, TanStack Query, vitest, Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-19-phase-2b-cpi-design.md` (read it first; the ECT code is the pattern: `adapters/ect/`, `insights/ect.py`, `tests/adapters/test_ect.py`, `tests/ect_support.py`, `pages/ElectronicCardTransactions.tsx`, `charts/ect.ts`).

## Global Constraints

- 10 s crawl delay on stats.govt.nz is a hard constraint: real-site fetches only through the shared paced `Fetcher`/`FilePacer`, sequentially, only in Task 1 and the explicitly marked live step in Task 14. Never lower the delay, never parallelise.
- No synthetic values in production code paths. Fixtures are real excerpts of official files. Do not invent September 2026 values or hardcode future dates.
- Timestamps stored UTC, shown in Pacific/Auckland.
- Never plot monthly and year-ended series on one axis; this phase has quarterly series only. Component price change (%), percentage-point contribution and share of total movement are three different measures and are never interchanged or relabelled.
- Last-known-good data must survive any failed update; success means downloaded, parsed, validated and committed in one transaction.
- Never loosen a validation threshold without evidence from the real file, and add a regression test. Tolerances in this plan marked MEASURED are set from Task 1 measurements and recorded in `docs/data-sources/cpi.md`.
- Error text stored or served by the API must not include raw exception messages. Upstream text in tooltips/CSV export goes through `escapeHtml` / `toCsv`.
- Do not alter migration or ECT calculations. Existing tests must keep passing.
- Python: ruff line length per `pyproject.toml`; `from __future__ import annotations`; type hints. Commit prefixes: `feat(cpi):`, `test(cpi):`, `docs(cpi):`, `fix(cpi):`. End every commit message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Missing values in the source are `0` or `NA`. Both mean missing, never zero.
- Use the csv module, not pandas, in production code. In any ad hoc analysis read `Period` as a string (`"2017.06"` otherwise becomes a float).

## Review Focus

1. A release page that lists a renamed, missing or extra CSV: ingest fails `layout_changed`, last-known-good unchanged, no vintage written (Task 6).
2. A core series whose reference-quarter value is `NA`/`0`: the bundle is rejected, not stored as zero or silently shortened (Task 5).
3. Chart text drift ("Tradeables" vs "Tradables", "Housing contents" vs "Household contents"): names map to official CSV names; an unmappable group in a present contribution chart fails the bundle (Task 5).
4. A rebased index (base quarter no longer 1000): fail closed with a methodology message, never mixed bases (Task 5).
5. Re-ingesting the same release, or a release whose reference quarter is not a quarter end or postdates publication: unchanged / rejected, no duplicate vintages (Task 6).
6. Seasonally adjusted history revised in a newer release: stored as a genuine revision with a warning, not a failure (Task 6).
7. Discontinued optional Level-2/3 series (e.g. SA series ending 2023.03): warning only, headline CPI still ingests (Task 5).
